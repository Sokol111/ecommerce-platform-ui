# AGENTS.md

## Stack and Commands

This is a Nuxt 4 / TypeScript platform UI managed with pnpm.

```bash
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
pnpm link:local          # use the sibling tenant API TypeScript package
pnpm unlink:local        # restore the packaged API dependency
```

Do not edit `.nuxt/` or `.output/`. Keep real values in ignored `.env`; only non-secret defaults
belong in `.env.example`.

`pnpm link:local` and `pnpm unlink:local` are only for running the UI directly on the host. When
using `make dev` from `ecommerce-infrastructure/environments/local`, Tilt builds the local Nuxt
image with `Dockerfile.nuxt`: it copies and builds each configured API's `gen/typescript`, removes
the packaged `@sokol111/*` dependencies, and links those local packages inside the container. Do
not run the link commands for that workflow.

## Structure and Boundaries

- `app/` contains pages, components, composables, and client UI.
- `server/api/` is the Nitro BFF boundary; browser code calls local `/api` routes.
- `server/utils/tenant-client.ts` is for service-to-service registration and management calls;
  `tenant-client-user.ts` is for user-scoped tenant calls. Preserve that distinction.
- Preserve session guards, API-permissions middleware, bearer-token handling, and tenant context.

## API Contracts

The tenant client is generated by `ecommerce-tenant-service-api`. Never edit its
`gen/typescript` output: change the owning `.proto` and run that repo's `make generate`. Use
`pnpm link:local` only for cross-repository API development.
